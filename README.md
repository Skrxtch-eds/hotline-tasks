# HotLine tasks

Трекер задач с дедлайнами, календарём и обратным отсчётом.

[Открыть сайт](https://skrxtch-eds.github.io/hotline-tasks/)

## Возможности

- Добавление, редактирование и удаление задач.
- Выбор даты и времени, быстрый срок «До конца дня» (23:59).
- Отметка выполнения.
- Фильтры и сортировка по сроку или порядку добавления.
- Обратный отсчёт и шкала времени до дедлайна.
- Подсветка просроченных задач.
- Сохранение данных в браузере.
- Адаптивный интерфейс.

## Технологии

HTML, CSS, JavaScript. Без библиотек и сборки.

## Запуск

Открой `index.html` в современном браузере или запусти локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем перейди на http://localhost:8000.

## Файлы

- `index.html` — разметка.
- `styles.css` — оформление и анимации.
- `app.js` — задачи, хранение и таймеры.
- `date-picker.js` — календарь и выбор времени.
- `assets/logo.png` — логотип и иконка вкладки.
- `fire.png` — огонёк на шкале дедлайна.
- `assets/` — графика и локальный шрифт Manrope (лицензия в `assets/fonts/OFL.txt`).

Данные хранятся в localStorage текущего браузера. Синхронизации между устройствами нет;
очистка данных сайта удалит задачи.
